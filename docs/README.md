# Dokumentation

Detaljer bakom [README](../README.md). Läs i den här ordningen om du ska ändra i koden:

- [Designbeslut](designbeslut.md): varför indata läses som okänd JSON, hur fel hanteras och varför IG-versionen är låst.
- [Diff-motorn](diff-motorn.md): `diffResources`, matchning av listor, flyttar och stavningsvarningar.
- [Svenska ändringsbeskrivningar](svenska-beskrivningar.md): `describeChanges` och etikettdatan per HVO-profil.
- [Jämförelsesidan](jamforelsesidan.md): sidan, filtren, Lista och Karta.
- [Granskningsrapport](granskningsrapport.md): export till Markdown och PDF.
- [Testdata](testdata.md): exemplen ur IG-paketet.

Regler för kod och arkitektur står i [CLAUDE.md](../CLAUDE.md).
